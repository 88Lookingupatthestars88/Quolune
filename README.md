# Quolune

Quolune 应用作为中国古风安卓的听书应用，致力于为用户提供优质的听书体验，欢迎大家使用。

## 能做什么

- 当系统朗读引擎。
- 在本应用里读书、听书。
- 多角色朗读。
-  自动识别书中角色。
-  并且能够针对性地调整每句话的人员。
-  接入 AI 的功能，可以让选择的提供商进行。
