# Quolune

Quolune 是一款中国古风的安卓听书应用。将第三方语音服务接入为系统朗读引擎，在本地阅读、聆听，
并可按角色分派不同音色进行多人播讲。

## 能做什么

- 当系统朗读引擎。
- 在本应用里读书、听书。
- 多角色朗读。
- 自动识别书中角色。
- 并且能够针对性地调整每句话的人员。
- 接入 AI 的功能，可以让你选择提供商，为你识别书中角色为其分配音色。未识别出的句子，可以让 AI 帮你去分配给对应角色。
