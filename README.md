# Quolune

Quolune 是一款中国古风的安卓听书应用。把语音服务商接进来当音色，在本地读书、听书，
按角色分派不同音色做多人播讲；也可以把自己交给系统，当手机的朗读引擎用。

## 能做什么

- 在本应用里读书、听书。
- 多角色朗读，逐句改派说话人与音色。
- 自动识别书中角色；认不出的句子可交给 AI 分配。
- 用手机上已装的朗读引擎念，离线、不花钱。
- 按一段录音复刻嗓音，或按一句描述造一副。
- 音色包导入导出，换手机带走。
- 当系统朗读引擎，别的应用也能用这里的声音。

## 本应用的存储功能

本应用不具备服务器，也不设账号系统。您导入的书籍、阅读位置、角色表、音色配置、服务商密钥，
全部存放在本机应用私有目录：不上传、不同步。系统备份与换机迁移见[隐私政策](PRIVACY.md)第五节。

本应用不收集您的任何个人信息，只向系统查询本机装了哪些朗读语音包，用于列出可导入的话音。
详细的权限用途与数据流向见 [隐私政策](PRIVACY.md)。
